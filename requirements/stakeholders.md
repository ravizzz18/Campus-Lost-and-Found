
# Stakeholder Identification

| Stakeholder | Role | Interest |
|---|---|---|
| Students | Primary users | Report lost items and recover belongings |
| College Staff | Users | Report and manage found items |
| System Administrator | System manager | Manage users, reports and claims |
| College Management | Institutional stakeholder | Improve campus resource management |
| Development Team | System developers | Design, develop, test and maintain the application |

## Stakeholder Responsibilities

### Students
- Submit lost item reports.
- Register found belongings.
- Search available records.
- Submit ownership claims.

### College Staff
- Report found belongings.
- Assist in identifying item owners.
- Coordinate recovery when required.

### System Administrator
- Review item reports.
- Verify ownership claims.
- Manage reported item records.
- Update recovery statuses.

### College Management
- Provide institutional support.
- Define policies for handling recovered belongings.

### Development Team
- Gather requirements.
- Design and implement the application.
- Test functionality.
- Maintain project documentation.
