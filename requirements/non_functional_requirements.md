# Non-Functional Requirements

## NFR-01: Usability
The application shall provide a simple and user-friendly interface that can be easily understood by students and college staff.

## NFR-02: Performance
The application should respond to normal user requests within a reasonable time under expected campus usage.

## NFR-03: Security
The system shall protect user credentials and restrict access to administrative functionality through role-based authorization.

## NFR-04: Reliability
The system shall maintain accurate records of reported items, ownership claims and recovery statuses.

## NFR-05: Data Integrity
The system shall validate user inputs and maintain consistent information in the database.

## NFR-06: Maintainability
The application shall use a modular architecture to make future modifications and maintenance easier.

## NFR-07: Compatibility
The application shall support commonly used modern web browsers and different screen sizes.

## NFR-08: Privacy
The system shall restrict access to personal information and avoid unnecessarily exposing sensitive item details.

## NFR-09: Availability
The application should be accessible whenever the development or deployment environment is operational.

## NFR-10: Scalability
The application architecture should allow future expansion to accommodate additional users and campus requirements.
