# Functional Requirements

## FR-01: User Authentication
The system shall allow users to register, log in and log out securely.

## FR-02: User Roles
The system shall support student, college staff and administrator roles.

## FR-03: User Profile
The system shall allow users to view and manage their basic profile information.

## FR-04: Report Lost Items
The system shall allow users to report lost belongings by entering the item name, description, category, date and location.

## FR-05: Report Found Items
The system shall allow users to report found belongings with relevant descriptions, photographs, date and location.

## FR-06: Item Search
The system shall allow users to search for lost and found items.

## FR-07: Item Filtering
The system shall allow users to filter items by category, location and date.

## FR-08: Item Details
The system shall display detailed information about reported items.

## FR-09: Ownership Claims
The system shall allow authenticated users to submit claims for items they believe belong to them.

## FR-10: Claim Verification
The administrator shall be able to review, approve or reject ownership claims.

## FR-11: Item Status Management
The administrator shall be able to update item statuses, including reported, claimed and recovered.

## FR-12: Administrative Dashboard
The system shall provide administrators with facilities to manage users, item reports and ownership claims.
