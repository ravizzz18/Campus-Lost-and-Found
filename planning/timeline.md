
# Project Timeline
## Campus Lost and Found Management System

The project is divided into seven major phases. Each phase has specific activities, responsible team members and expected deliverables.

| Phase | Activities | Responsibility | Deliverable |
|---|---|---|---|
| 1. Project Planning | Problem identification, objectives, scope, requirements and WBS | Kuldeep | Project plan and requirements |
| 2. Software Design | Process model, DFDs, data dictionary, sequence and architecture diagrams | Kuldeep, Meghana, Prathikshaa | Software design documents |
| 3. Frontend Development | Wireframes, authentication, dashboard, reporting and search interfaces | Ravindra | Frontend prototype |
| 4. Backend Development | FastAPI setup, authentication, item reporting and claim APIs | Prathikshaa | Backend APIs |
| 5. Database Management | Schema design, database models and user, item and claim tables | Meghana | Database implementation |
| 6. Testing and Integration | Module testing, frontend-backend integration and end-to-end testing | All team members | Integrated working prototype |
| 7. Documentation and Submission | Report, ethics documentation, GitHub/Jira evidence and presentation | All team members | Final report and presentation |

## Progress Tracking

Project activities are tracked using Jira. Tasks are assigned to individual team members and monitored through the following statuses:

- To Do
- In Progress
- In Review
- Done

GitHub is used for source-code management, documentation and maintaining project history.

**Note:** The timeline represents the planned project sequence. Exact task dates and durations will be maintained in Jira when finalized.
