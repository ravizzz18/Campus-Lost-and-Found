
# Work Breakdown Structure (WBS)
## Campus Lost and Found Management System

### 1. Project Planning
- 1.1 Define the problem statement
- 1.2 Define project objectives
- 1.3 Identify project stakeholders
- 1.4 Identify functional requirements
- 1.5 Identify non-functional requirements
- 1.6 Define project scope
- 1.7 Prepare project schedule and task allocation

### 2. Software Design
- 2.1 Select and justify the software process model
- 2.2 Prepare Data Flow Diagram (DFD) Level 0
- 2.3 Prepare Data Flow Diagram (DFD) Level 1
- 2.4 Prepare Data Flow Diagram (DFD) Level 2
- 2.5 Prepare the data dictionary
- 2.6 Prepare UML sequence diagram
- 2.7 Prepare system architecture diagram

### 3. Frontend Development
- 3.1 Design frontend wireframes
- 3.2 Set up React and TypeScript
- 3.3 Develop authentication interface
- 3.4 Develop student dashboard
- 3.5 Develop lost and found reporting forms
- 3.6 Develop item search and filtering interface

### 4. Backend Development
- 4.1 Set up FastAPI backend
- 4.2 Define REST API requirements
- 4.3 Implement authentication APIs
- 4.4 Implement lost item APIs
- 4.5 Implement found item APIs
- 4.6 Implement claim management APIs

### 5. Database Management
- 5.1 Design database schema
- 5.2 Create database models
- 5.3 Implement user tables
- 5.4 Implement item tables
- 5.5 Implement claim tables

### 6. Testing and Integration
- 6.1 Test authentication functionality
- 6.2 Test frontend functionality
- 6.3 Test database operations
- 6.4 Integrate frontend and backend
- 6.5 Perform end-to-end testing
- 6.6 Fix identified issues

### 7. Documentation and Submission
- 7.1 Prepare project report
- 7.2 Prepare ethics and risk documentation
- 7.3 Capture GitHub and Jira evidence
- 7.4 Prepare project presentation
- 7.5 Prepare final project demonstration
